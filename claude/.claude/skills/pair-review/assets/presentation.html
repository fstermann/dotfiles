What it is

Not an automatic AI review

⚙Automatic AI review

  • A bot reads the PR and posts comments on its own
  • It often sees only the diff, so some findings miss the point
  • No reviewer owns the comments

/pair-review

  • You read the code and write the comments
  • Tag a comment and Claude answers in that thread
  • Nothing is posted until you submit the review

Most useful when you review someone else's PR, or answer a review of your own.

Claude's replies start with a mark: ❊ answered, fixed, partly done, needs you.

Why not a normal session

Keep reading while Claude answers

In a session you leave the PR for each question: switch to the terminal, point Claude at the file and line or paste the code, wait, then find your place again. Or you collect your questions and ask at the end.

With /pair-review you tag a comment with /ask and keep reading. Claude answers in that thread within a minute, while you are on the next file.

At the last file the answers are already there. Read them, /reply, submit.
